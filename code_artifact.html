DEVELOPMENT JOURNEY

🎲 故事骰子進化歷程

從簡單的 3D 骰子，進化為整合 AI 生成的一頁式敘事平台

1️⃣
Phase 1.0 原型開發

3D 視覺骰子與六面互動

設計出包含表情、動作、物品等類別的 3D 翻轉骰子，支援點擊單顆重擲與簡單記事本記錄。

2️⃣
Phase 2.0 題庫與體驗擴充

四大主題庫與自訂骰子數量

擴充童話、科幻、偵探、日常四大主題庫，並提供 1~6 顆骰子自由切換與填空引導範本。

3️⃣
Phase 3.0 智慧生成

自動匯入元素與雙引擎故事生成

實現「擲出直接自動生成故事」功能，同時提供「算法速編模式」與「OpenAI GPT 深度模式」。

4️⃣
Phase 4.0 官網生態

一頁式亮色官網展示平台

打造全方位清新明亮展演網頁《浮空創世紀》，整合 3D 浮空骰子、歷程展示與實機體驗導覽。
